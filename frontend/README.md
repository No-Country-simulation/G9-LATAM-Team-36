# Frontend — EnergiAI (React + Vite + Tailwind)

Dueño: Bloque I

## Setup
```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Por defecto `VITE_USE_MOCK=true`: funciona completo sin el backend corriendo.
Cuando el Bloque E entregue la API, cambia a `VITE_USE_MOCK=false`.
